# 检查触发插件股票脚本

## 功能说明
检查哪些股票在当前交易日（或指定日期）触发了C点插件或R点插件。

## 使用方法

### Windows
双击运行 `check_plugins.bat`

或者在命令行运行：
```bash
cd backend\scripts
python check_plugins_triggered.py
```

### Linux/Mac
```bash
cd backend/scripts
python3 check_plugins_triggered.py
```

## 前置条件
1. 后端服务必须运行（`http://localhost:5000`）
2. 已经计算过历史CR点数据
3. Python环境已配置好

## 输出内容

### 实时进度
脚本会实时显示检查进度：
```
[1/100] 检查 SH600000 浦发银行 (波段)...
  ✅ 触发插件!
     【策略1插件】
       - 横盘突破: 检测到横盘突破形态
       基础分: 65.00, 最终分: 75.00
```

### 汇总报告
检查完成后会输出详细汇总：

1. **统计数据**
   - 总股票数
   - 成功/失败数量
   - 触发插件的股票数量

2. **详细列表**
   - 股票代码、名称、股性
   - 触发的插件类型和原因
   - 策略分数变化
   - 是否触发C点/R点

3. **简洁列表**
   - 快速查看所有触发插件的股票

## 脚本原理

1. 从 `StockGroups` 获取所有股票列表
2. 遍历每个股票，调用 `http://localhost:5000/api/latest_cr_points` 接口
3. 检查返回结果中的 `strategy1.plugins` 和 `r_point.plugins`
4. 汇总并输出结果

## 插件类型

### C点插件（strategy1.plugins）
- 横盘突破
- 持续上涨
- 底部反转
- 等等...

### R点插件（r_point.plugins）
- 乖离率偏离
- 临近压力位滞涨
- 基本面突发利空
- 高位发散
- 上冲乏力
- 箱体回踩
- 等等...

## 日志输出
脚本会输出详细日志到控制台，包含：
- 检查进度
- 触发的插件详情
- 错误信息（如果有）
- 最终汇总报告

## 注意事项

1. **确保后端服务运行**
   - 如果后端未启动，脚本会报错
   - 检查 http://localhost:5000 是否可访问

2. **执行时间**
   - 根据股票数量，执行时间可能较长（5-30分钟）
   - 每个股票需要实时计算历史CR点

3. **网络超时**
   - 默认超时时间：30秒/股票
   - 如果经常超时，可能需要优化后端性能

4. **数据依赖**
   - 需要历史K线数据
   - 需要历史赔率数据（b_daily_chance表）
   - 需要成交量类型数据

## 修改检查日期

如需检查其他日期，可以修改脚本中的逻辑，或者在命令行传入参数。

## 故障排除

### 问题：连接失败
**解决**：确保后端服务运行在 http://localhost:5000

### 问题：所有股票都报错
**解决**：检查数据库连接和数据完整性

### 问题：执行很慢
**解决**：
- 首次执行需要计算历史CR点，会比较慢
- 后续执行会快一些（使用缓存）
- 可以先对少量股票测试

### 问题：某些股票超时
**解决**：
- 可能是该股票数据量大或计算复杂
- 检查该股票的K线数据是否正常
- 增加超时时间
