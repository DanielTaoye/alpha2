# 全部A股每日机会数据同步脚本

## 功能说明

这个脚本用于从 `all_stock` 表获取所有未退市的股票，调用外部接口获取每日机会数据，并保存到 `b_daily_chance` 表。

## 脚本文件

`sync_all_stocks_daily_chance.py`

## 使用方法

### 1. 测试模式（推荐先测试）

测试指定数量的股票，用于验证脚本是否正常工作：

```bash
cd backend
python scripts/sync_all_stocks_daily_chance.py --test 5
```

参数说明：
- `--test N`: 只处理前N支股票，用于测试

### 2. 全量同步模式

处理所有未退市的股票：

```bash
cd backend
python scripts/sync_all_stocks_daily_chance.py
```

系统会提示确认，输入 `y` 继续，输入其他字符取消。

## 功能特点

1. **自动过滤退市股票**: 从 `all_stock` 表查询时自动过滤掉 `是否退市 = 1` 的股票

2. **同步股性信息**: 从 `all_stock` 表的 `nature` 字段获取股性（波段、中长线、短线等）

3. **调用外部接口**: 调用 `http://121.5.174.81:8005/stock/getDailyChanceWithBeauty` 接口获取数据

4. **正确解析赔率得分**: 从接口返回的 `winRatioDescription` 字段中解析：
   - 格式示例：`【此为波段赔率算法】日线赔率得分：13.83，周线赔率得分：0.00，赔率总分：13.83`
   - 自动提取日线、周线、总赔率得分

5. **批量保存数据**: 将获取的数据批量保存到 `b_daily_chance` 表

6. **自动去重**: 使用 `ON DUPLICATE KEY UPDATE` 语句，避免重复数据

7. **详细日志**: 记录每个股票的处理结果，包括股性、成功、失败、无数据等状态

8. **统计信息**: 完成后输出统计信息，包括：
   - 总股票数
   - 成功数量
   - 无数据数量
   - 失败数量
   - 总记录数
   - 耗时

## 数据字段

保存到 `b_daily_chance` 表的字段：

- `stock_code`: 股票代码
- `stock_name`: 股票名称
- `stock_nature`: 股性（当前为空，后续可补充）
- `date`: 日期
- `chance`: 机会概率
- `day_win_ratio_score`: 日线赔率得分
- `week_win_ratio_score`: 周线赔率得分
- `total_win_ratio_score`: 赔率总分
- `support_price`: 支撑价格
- `pressure_price`: 压力价格

## 注意事项

1. **超时问题**: 某些股票的接口可能会超时（默认30秒），这是正常现象，脚本会自动跳过继续处理下一个

2. **运行时间**: 全量同步所有A股需要较长时间，建议在非交易时段进行

3. **网络稳定性**: 确保网络连接稳定，接口地址 `121.5.174.81:8005` 可访问

4. **数据库连接**: 确保本地数据库配置正确（`config_local.py` 或 `config_server.py`）

5. **请求间隔**: 脚本已设置 0.5 秒的请求间隔，避免对接口造成压力

## 常见问题

### Q: 如何查看同步的数据？

A: 可以使用以下SQL查询：

```sql
-- 查看已同步的股票统计
SELECT stock_code, stock_name, COUNT(*) as count 
FROM b_daily_chance 
GROUP BY stock_code, stock_name;

-- 查看指定股票的数据
SELECT * FROM b_daily_chance 
WHERE stock_code = 'SH600004' 
ORDER BY date DESC 
LIMIT 10;
```

### Q: 如何重新同步某些股票的数据？

A: 直接运行脚本即可，脚本会使用 `ON DUPLICATE KEY UPDATE` 自动更新已存在的数据。

### Q: 如何只同步指定股票？

A: 可以修改脚本中的 SQL 查询条件，添加 `WHERE code IN ('SH600004', 'SH600007')` 等条件。
