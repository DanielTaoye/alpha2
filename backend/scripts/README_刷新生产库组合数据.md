# 刷新生产数据库多头和空头组合脚本

## 脚本说明

`refresh_patterns_production.py` 用于刷新生产数据库中60支股票的多头组合和空头组合数据。

## 功能特点

- ✅ 直连生产数据库（腾讯云）
- ✅ 自动获取配置中的60支股票
- ✅ 批量计算多头组合（BullishPatternService）
- ✅ 批量计算空头组合（BearishPatternService）
- ✅ 批量更新到 `b_daily_chance` 表
- ✅ 详细的日志输出和进度显示
- ✅ 错误处理和统计

## 使用方法

### 1. 进入脚本目录

```bash
cd backend/scripts
```

### 2. 运行脚本

```bash
python refresh_patterns_production.py
```

## 执行流程

1. **连接生产数据库**
   - 验证数据库连接

2. **获取股票列表**
   - 从 `StockGroups` 配置中获取60支股票

3. **逐个处理股票**
   - 查询该股票在 `b_daily_chance` 表中的所有日期
   - 对每个日期计算多头组合
   - 对每个日期计算空头组合
   - 批量更新到数据库

4. **输出统计结果**
   - 成功处理的股票数
   - 失败的股票列表
   - 总更新记录数

## 注意事项

### ⚠️ 重要提示

1. **生产环境操作**
   - 此脚本直接操作生产数据库
   - 建议在非交易时间执行
   - 建议先在测试环境验证

2. **数据备份**
   - 执行前建议备份 `b_daily_chance` 表
   - 可使用以下SQL备份：
   ```sql
   CREATE TABLE b_daily_chance_backup_20250115 
   SELECT * FROM b_daily_chance;
   ```

3. **执行时间**
   - 60支股票，每支约1000-2000条记录
   - 预计执行时间：10-30分钟
   - 取决于网络速度和数据量

4. **网络要求**
   - 需要能访问腾讯云数据库
   - 确保IP已加入白名单

## 更新内容

脚本会更新 `b_daily_chance` 表的以下字段：

- `bullish_pattern`: 多头组合（如："十字星+中阳线,触底反弹阳线+阳线"）
- `bearish_pattern`: 空头组合（如："放量冲高回落阴线+次日未反包,乌云盖顶"）

## 故障排查

### 连接失败

```
错误: Can't connect to MySQL server
```

**解决方案**：
1. 检查网络连接
2. 确认IP在腾讯云白名单中
3. 验证数据库凭证是否正确

### 计算失败

```
错误: 计算日期 2025-01-15 的组合失败
```

**解决方案**：
1. 检查K线表数据是否完整
2. 查看详细错误日志
3. 确认表名配置正确

### 更新失败

```
错误: 批量更新失败
```

**解决方案**：
1. 检查数据库权限
2. 确认表结构正确
3. 查看数据库连接状态

## 维护说明

### 添加新的组合模式

1. 在 `BullishPatternService` 或 `BearishPatternService` 中添加新的 `_check_patternN` 方法
2. 在 `identify_*_patterns` 方法中调用新方法
3. 重新运行本脚本刷新数据

### 修改股票列表

1. 修改 `backend/infrastructure/config/stock_config.json`
2. 重新运行脚本即可
