# 定时任务部署到服务器

## 📦 需要上传的文件

```
backend/scripts/
├── daily_chance_scheduler.py          # ✅ 主程序
├── daily_chance_scheduler_test.py     # ✅ 测试脚本
├── start_daily_chance_scheduler.sh    # ✅ 启动脚本
├── stop_daily_chance_scheduler.sh     # ✅ 停止脚本
├── check_scheduler_status.sh          # ✅ 状态检查
├── test_sync_once.sh                  # ✅ 测试脚本
└── README_定时任务部署说明.md         # ✅ 说明文档

backend/infrastructure/config/
└── stock_config.json                  # ✅ 股票配置（59支股票）

backend/domain/services/
└── volume_type_service.py             # ✅ 成交量类型计算服务
```

## 🚀 快速部署命令

### 1. 上传文件

```bash
# 使用scp上传（替换your_server为实际服务器地址）
scp -r backend/scripts root@your_server:/path/to/alpha_strategy_v2/backend/
scp backend/infrastructure/config/stock_config.json root@your_server:/path/to/alpha_strategy_v2/backend/infrastructure/config/
```

或使用FTP/SFTP工具上传。

### 2. 连接服务器

```bash
ssh root@your_server
cd /path/to/alpha_strategy_v2
```

### 3. 赋予执行权限

```bash
cd backend/scripts
chmod +x *.sh
```

### 4. 测试运行

```bash
# 测试一次完整的同步流程
bash test_sync_once.sh
```

查看输出，确认：
- ✅ 数据库连接成功
- ✅ API访问成功  
- ✅ 数据写入成功

### 5. 启动定时服务

```bash
bash start_daily_chance_scheduler.sh
```

### 6. 验证服务状态

```bash
bash check_scheduler_status.sh
```

## 📋 执行时间说明

**默认执行时间：每天 17:00**

为什么选择17:00？
- 市场收盘时间：15:00
- 数据生成时间：15:30 - 16:30
- 同步时间：17:00 ✅ （确保数据已生成完毕）

## 🔍 常见问题

### Q1: 如何修改执行时间？

编辑 `daily_chance_scheduler.py` 第 XXX 行：

```python
trigger=CronTrigger(hour=17, minute=0)  # 修改为需要的时间
```

### Q2: 如何查看执行历史？

```bash
cat logs/daily_chance_scheduler.log | grep "定时任务完成"
```

### Q3: 如何手动触发一次同步？

```bash
bash test_sync_once.sh
```

### Q4: 服务异常重启怎么办？

如果使用 systemd 服务配置（见 README），服务会自动重启。

否则需要手动重启：

```bash
bash stop_daily_chance_scheduler.sh
bash start_daily_chance_scheduler.sh
```

### Q5: 如何验证数据已更新？

登录数据库查询：

```sql
-- 查看今天更新的数据
SELECT stock_code, date, total_win_ratio_score, volume_type, updated_at
FROM b_daily_chance
WHERE date = CURDATE()
ORDER BY updated_at DESC;

-- 统计今天更新的股票数
SELECT COUNT(DISTINCT stock_code) as updated_count
FROM b_daily_chance
WHERE date = CURDATE() AND DATE(updated_at) = CURDATE();
```
