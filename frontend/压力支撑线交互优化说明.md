# 压力支撑线交互优化说明

## 🎯 优化目标

**问题：** 原来只有鼠标悬停在K线实体上才会显示压力支撑线，交互不够友好。

**优化后：** 鼠标在K线对应的整个垂直区域（任意位置）都能触发显示压力支撑线。

---

## 📊 对比说明

### 优化前 ❌

```
只有鼠标在K线实体（红色或绿色柱子）上才触发

        │
    ┌───┼───┐  ← 鼠标在这里：✅ 显示
    │   │   │
```

- 用户体验不好

## 🔧 技术实现

### 修改前：使用 `mouseover` 事件

```javascript
chart.on('mouseover', function(params) {
    // 只有params指向K线实体时才触发
    if (params.componentType === 'series' && 
        params.seriesName === 'K线' && 
        params.name) {
        // 显示压力支撑线
    }
});
```

**问题：** `mouseover` 只在鼠标悬停在特定series（K线）上时触发。

---

### 修改后：使用 `updateAxisPointer` 事件

```javascript
chart.on('updateAxisPointer', function(event) {
    // 获取鼠标指向的x轴数据索引
    const xAxisInfo = event.axesInfo[0];
    if (xAxisInfo && xAxisInfo.value !== undefined) {
        const dataIndex = xAxisInfo.value;
        const dateStr = dates[dataIndex];
        // 显示该日期的压力支撑线
    }
});
```

**优势：** 
- `updateAxisPointer` 在鼠标移动到图表任意位置时触发
- 通过x轴索引获取对应的日期
- 无需依赖特定的series

## ⚡ 性能优化

### 问题：频繁更新影响性能

鼠标移动时会频繁触发事件，如果每次都更新图表会影响性能。

### 解决方案：记录上次日期，避免重复更新

```javascript
let lastHoverDate = null;  // 记录上次悬停的日期

chart.on('updateAxisPointer', function(event) {
    const dateOnly = dates[dataIndex].split(' ')[0];
    
    // 如果是同一个日期，不重复更新
    if (dateOnly === lastHoverDate) {
        return;
    }
    lastHoverDate = dateOnly;
    
    // 更新压力支撑线
    chart.setOption({ ... });
});
```

**效果：** 只有切换到新日期时才更新，同一日期内移动不触发更新。

## 🎮 使用体验对比

### 场景1：查看普通K线

**优化前：**
1. 移动鼠标到K线实体
2. 需要精确对准
3. 如果偏离一点就不显示

**优化后：**
1. 鼠标移动到该日期的垂直区域
2. 无需精确对准
3. 整个区域都能触发

---

### 场景2：查看十字星

**优化前：**
1. 十字星实体很小
2. 很难对准
3. 容易miss掉

**优化后：**
1. 鼠标在该日期区域即可
2. 轻松触发
3. 不会miss

---

### 场景3：查看成交量异常的日期

**优化前：**
1. 在成交量区域移动
2. 不会触发压力支撑线
3. 需要移动到K线区域

**优化后：**
1. 在成交量区域移动
2. 也能触发压力支撑线
3. 无需切换区域
