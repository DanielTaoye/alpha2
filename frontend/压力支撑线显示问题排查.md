# 压力支撑线显示问题排查

## 🔍 问题现象

**现象：** 有些K线鼠标hover可以显示压力/支撑线，有些不能显示

---

## 📋 原因分析

### 根本原因

压力线和支撑线的数据来自数据库表 `b_daily_chance`，如果某个日期的记录中：
- `support_price` 字段为 `NULL` 
- `pressure_price` 字段为 `NULL`

那么这个日期就**无法显示压力/支撑线**。

### 数据加载逻辑

```javascript
// 只有当数据不为 null/undefined 时才加载到Map中
if (item.supportPrice !== undefined && item.supportPrice !== null) {
    supportPriceMap[dateStr] = item.supportPrice;
}
if (item.pressurePrice !== undefined && item.pressurePrice !== null) {
    pressurePriceMap[dateStr] = item.pressurePrice;
}
```

### 2️⃣ 查询数据库

连接数据库，查看某只股票的压力/支撑线数据：

```sql
-- 查看某只股票的压力支撑线数据
SELECT 
    date, 
    support_price, 
    pressure_price,
    CASE 
        WHEN support_price IS NULL AND pressure_price IS NULL THEN '缺失'
        WHEN support_price IS NULL THEN '缺支撑'
        WHEN pressure_price IS NULL THEN '缺压力'
        ELSE '完整'
    END as status
FROM b_daily_chance 
WHERE stock_code = 'SH600000' 
ORDER BY date DESC 
LIMIT 20;
```

#### 统计缺失情况
```sql
-- 统计压力支撑线数据完整性
SELECT 
    stock_code,
    COUNT(*) as total,
    SUM(CASE WHEN support_price IS NOT NULL THEN 1 ELSE 0 END) as has_support,
    SUM(CASE WHEN pressure_price IS NOT NULL THEN 1 ELSE 0 END) as has_pressure,
    SUM(CASE WHEN support_price IS NULL AND pressure_price IS NULL THEN 1 ELSE 0 END) as missing
FROM b_daily_chance 
WHERE stock_code = 'SH600000'
GROUP BY stock_code;
```

## 🔨 解决方案

### 方案1：重新计算压力支撑线（推荐）

运行daily_chance计算脚本，重新生成压力支撑线数据：

```bash
cd backend/scripts
python calculate_daily_chance.py -s SH600000
```

或批量计算所有股票：

```bash
python calculate_daily_chance.py --all
```

---

### 方案2：使用调度脚本定期更新

设置定时任务，每日自动更新：

```bash
# 启动调度器
cd backend/scripts
python schedule_daily_chance.py
```

---

### 方案3：手动SQL更新（临时方案）

如果只是个别日期缺失，可以手动更新：

```sql
-- 更新指定日期的压力支撑线
UPDATE b_daily_chance 
SET 
    support_price = 1025,  -- 实际价格10.25 * 100
    pressure_price = 1250  -- 实际价格12.50 * 100
WHERE stock_code = 'SH600000' 
  AND date = '2024-01-05';
```

⚠️ **注意：** 数据库中存储的是整数（实际价格×100）

## 📊 数据完整性检查

### 检查脚本

创建一个检查脚本 `check_support_pressure.py`：

```python
"""检查压力支撑线数据完整性"""
import pymysql
from config import DATABASE_CONFIG

conn = pymysql.connect(**DATABASE_CONFIG)
cursor = conn.cursor()

# 查询各股票的数据完整性
query = """
SELECT 
    stock_code,
    COUNT(*) as total,
    SUM(CASE WHEN support_price IS NOT NULL THEN 1 ELSE 0 END) as has_support,
    SUM(CASE WHEN pressure_price IS NOT NULL THEN 1 ELSE 0 END) as has_pressure,
    ROUND(SUM(CASE WHEN support_price IS NOT NULL THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as support_rate,
    ROUND(SUM(CASE WHEN pressure_price IS NOT NULL THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as pressure_rate
FROM b_daily_chance 
GROUP BY stock_code
ORDER BY support_rate ASC
LIMIT 20;
"""

cursor.execute(query)
results = cursor.fetchall()

print("=" * 80)
print("压力支撑线数据完整性检查")
print("=" * 80)
print(f"{'股票代码':<15} {'总数据':<10} {'支撑线':<10} {'压力线':<10} {'支撑率':<10} {'压力率':<10}")
print("-" * 80)

for row in results:
    print(f"{row[0]:<15} {row[1]:<10} {row[2]:<10} {row[3]:<10} {row[4]:<10}% {row[5]:<10}%")

conn.close()
```

## 💡 常见情况

### 情况1：新股票数据未初始化

**现象：** 所有日期都没有压力支撑线

**解决：** 运行计算脚本初始化数据

### 情况2：近期数据未更新

**现象：** 只有老数据有压力支撑线，新数据没有

**解决：** 运行增量更新脚本

### 情况3：计算失败导致缺失

**现象：** 某些日期数据缺失

**原因：** 
- 该日期没有K线数据
- 历史数据不足（无法计算）
- 计算过程出错

**解决：** 查看计算日志，修复数据后重新计算
