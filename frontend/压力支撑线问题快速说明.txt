==================================
压力支撑线显示问题 - 快速说明
==================================

✅ 已修改：颜色统一为黄色

━━━━━━━━━━━━━━━━━━━━━━━━━━

❓ 为什么有些K线不显示压力支撑线？

原因：数据库中该日期的 support_price 或 pressure_price 字段为 NULL

━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 如何查看缺失情况？

1. 刷新页面 (F5)
2. 打开开发者工具 (F12)
3. 查看 Console 标签页
4. 查看日志：

   每日机会数据加载成功，总数据: 500 条
     - 支撑线: 320 条  ← 有数据的日期数
     - 压力线: 320 条
     - ⚠️ 缺少压力/支撑线数据: 180 条  ← 缺失数量

5. 鼠标hover到不显示的K线，查看日志：
   
   [压力支撑线] 2024-01-05 缺少数据
   [压力支撑线] 日期 2024-01-05 没有压力/支撑线数据

━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 快速解决方案

方案1：重新计算数据（推荐）
```bash
cd backend/scripts
python calculate_daily_chance.py -s SH600000
```

方案2：查看数据库
```sql
SELECT date, support_price, pressure_price
FROM b_daily_chance 
WHERE stock_code = 'SH600000' 
  AND (support_price IS NULL OR pressure_price IS NULL)
ORDER BY date DESC;
```

方案3：批量更新所有股票
```bash
cd backend/scripts
python calculate_daily_chance.py --all
```

━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 常见情况

✔ 新股票未初始化：运行计算脚本
✔ 近期数据未更新：运行增量更新
✔ 个别日期缺失：检查K线数据是否存在

━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 数据库字段说明

• support_price: 支撑价格（整数，实际价格×100）
  例如：1025 表示 10.25元

• pressure_price: 压力价格（整数，实际价格×100）
  例如：1250 表示 12.50元

• 如果字段为 NULL，则不显示该日期的压力支撑线
